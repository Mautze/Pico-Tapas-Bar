# PICO Tapas Bar – Website

Vollständige Website für das spanische Restaurant **PICO Tapas Bar** in Berlin Kreuzberg.

## Seiten
- **Start** (`index.html`) – Startseite mit Hero und Einführung
- **Menü** (`menu.html`) – Speisekarte mit Tapas und Hauptgerichten
- **Catering** (`catering.html`) – Catering-Pakete und Ablauf
- **Über uns** (`about.html`) – Geschichte und Werte
- **Galerie** (`gallery.html`) – Bildergalerie
- **Kontakt** (`contact.html`) – Kontaktformular, Adresse und Öffnungszeiten

## Design
- Rustikaler spanischer Stil (altes Dorf)
- Farben: Terrakotta, Olivgrün, warmes Beige, Holzbraun
- Responsive (mobilfreundlich)
- Schriftarten: Playfair Display + Lora (Google Fonts)

## So stellst du die Website online (kostenlos)

### Empfehlung 1: Cloudflare Pages (beste Wahl)
1. Gehe zu [https://pages.cloudflare.com](https://pages.cloudflare.com) und melde dich an (kostenlos).
2. Klicke auf **Create a project** → **Upload assets**.
3. Ziehe den gesamten Ordner `pico-tapas-bar` (oder die Dateien) hinein.
4. Fertig – deine Seite ist live unter einer `.pages.dev`-Adresse.
5. Optional: Eigene Domain verbinden.

### Empfehlung 2: Netlify (sehr einfach + Formulare)
1. Gehe zu [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Ziehe den Ordner einfach auf die Seite.
3. Die Seite ist sofort online.
4. Für das Kontaktformular kannst du später Netlify Forms aktivieren.

### Empfehlung 3: GitHub Pages
1. Erstelle ein neues Repository auf GitHub.
2. Lade alle Dateien hoch.
3. Gehe zu Settings → Pages → Source: Deploy from a branch → main / root.

## Hinweise
- Adresse, Telefon und E-Mail sind Platzhalter – bitte durch echte Daten ersetzen.
- Das Kontaktformular ist aktuell eine Demo (zeigt nur eine Erfolgsmeldung). Für echte E-Mails kannst du Formspree, Netlify Forms oder einen ähnlichen Service nutzen.
- Bilder kommen von Unsplash (kostenlos nutzbar).
